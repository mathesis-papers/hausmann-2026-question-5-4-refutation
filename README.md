# Residual order four in GP(7,2): an alternative proof for Hausmann's Question 5.4 (arXiv:2611.05178v1, Section 5), after AFTD (2026)

**Authors:** Haobo Ma, Wenlin Zhang

Following AFTD's negative answer dated November 5, 2026, to Hausmann's Question 5.4 in Weighted Max Cut in Subcubic Graphs (arXiv:2611.05178v1, Section 5), we give a different counterexample with an exact residual-order calculation: the generalized Petersen graph GP(7,2) has odd girth five, but deleting any independent set leaves a component with at least four vertices. We prove this by classifying its maximal independent sets into five symmetry classes. The bound four is attained on this graph. The same classification gives an obstruction to the nonempty-independent-side version of Question 5.3; its printed quantifiers admit an empty-side solution.
